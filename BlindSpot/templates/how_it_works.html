How BlindSpot Works

A beginner-friendly web security scanner for sites you own or are authorized to test.

What it checks

  1. HTTPS — Is your connection encrypted?
  2. Security Headers — Are important protective headers present?
  3. Exposed Resources — Are files like .env or backups publicly reachable?
  4. Directory Listing — Can visitors browse your raw file structure?
  5. Cookie Security — Are your cookies protected with Secure/HttpOnly/SameSite?
  6. Error Leakage — Do your error pages reveal stack traces or database details?

How it avoids false alarms

Before flagging an "exposed" file, BlindSpot compares the response against your real homepage. Some sites return the same page for every URL — that's not a real exposure, so BlindSpot skips it.

What it's not

BlindSpot is not a hacking tool, exploit generator, or penetration-testing replacement. It performs safe, read-only checks and reports what it finds in plain language — what it means, how serious it is, and what to do about it.
