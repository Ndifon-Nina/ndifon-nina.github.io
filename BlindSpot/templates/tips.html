Security Tips

Plain-language explanations of what BlindSpot checks and why it matters.

What is HTTPS?

HTTPS encrypts the connection between a visitor's browser and your website, so passwords, forms, and cookies can't be easily intercepted on the way.

What is a .env file, and why does it matter?

A .env file usually stores secret values like API keys, database passwords, and app secrets. If it's publicly accessible, anyone can read those secrets.

What are security headers?

Security headers are instructions your server sends to the browser, telling it how to behave safely — for example, blocking certain scripts or preventing your site from being embedded in a hidden frame on another site.

What is directory listing?

When enabled, it lets visitors see a raw list of every file in a folder on your server, instead of just the page you intended them to see — which can expose files you forgot were there.

Why do error pages matter?

A friendly error page just says "something went wrong." A leaky one shows a stack trace, database engine name, or file paths — clues an attacker can use to plan an attack.

Why protect API keys?

An exposed API key can let someone impersonate your app, rack up usage charges on your account, or access data they shouldn't be able to reach.
