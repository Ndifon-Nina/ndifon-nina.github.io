BlindSpot

Python · Flask · Security

A website security scanner. You sign up, submit a URL you own, and it checks for common problems: missing security headers, exposed files like .env and .git/config, open directory listing, and error messages that leak too much information. It gives each site a score and explains what to fix and why.

MoMoSafe237

Python · Flask · Security · SQLite

A mobile money scam detection and reporting tool for Cameroon. You can check a phone number against reported scams, paste a message to see how suspicious it looks, report a scammer, and even dispute a wrong report. Built with rate limiting, login protections and an admin review system.
